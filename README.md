# Obsidian 多学科学习知识库

一套面向 ChatGPT、Codex 等 AI 协作学习场景的 Obsidian Vault 模板。

它不把完整聊天直接当作知识，而是通过“收集 → 查重 → 提炼 → 连接 → 复习”的流程，将对话、旧笔记和学习资料转化为可长期维护的原子知识。

## 主要特点

- 学科 MOC 与跨学科原子概念相结合
- 写入前搜索并合并已有知识
- 区分新知识、补充、冲突、来源和待验证内容
- 保留来源、可信度和更新时间
- 内置主动回忆题与复习流程
- 提供旧聊天和旧笔记批量导入提示词
- 使用 `AGENTS.md` 约束 Codex 等 AI 助手的写入行为

## 快速开始

1. 下载或克隆本仓库。
2. 使用 Obsidian 的“打开本地仓库”选择该目录。
3. 从 `00-首页/知识库首页.md` 开始。
4. 与 AI 学习结束后使用 `AI知识库协作提示词.md` 中的提示词整理知识。

推荐指令：

```text
请按学习知识库中的 AGENTS.md 整理本轮内容。先查重并给出新增、更新、冲突和跳过计划，我确认后再写入 Vault。
```

## 目录结构

```text
00-首页/          导航入口
01-收件箱/        未提炼的材料
10-学科/          学科 MOC
20-概念/          跨学科原子知识
30-方法与模型/    可复用的方法和思考模型
40-问题与探索/    未解决或待验证的问题
50-来源/          书籍、论文、课程和对话来源
60-复习/          主动回忆和复习安排
90-模板/          知识条、MOC、来源和学习会话模板
99-归档/          已替代或已完成提炼的材料
```

## 使用原则

- 先查重，再创建。
- 一条笔记围绕一个核心概念。
- 不确定内容明确标记，不伪造引用。
- 原始资料不静默删除。
- 大规模合并、移动或删除必须先经用户确认。
