# 机械波主动回忆题

使用方法：先在纸上作答，再展开答案。不要边看公式边做。

## 第一轮：概念

1. (\omega)、(k)、(f)、(\lambda) 各自描述什么？
2. 如何用等相位法判断传播方向？
3. 质点振动速度和波速有何区别？
4. 为什么驻波式的最大系数通常是单列行波振幅的两倍？
5. 为什么移动反射体产生两次多普勒频移？

## 第二轮：一分钟推导

1. 从 (\omega=2\pi f)、(k=2\pi/\lambda) 推出 (u=\omega/k)。
2. 对 (y=A\sin(\omega t-kx)) 求质点速度及最大值。
3. 用和差化积推导两列反向行波形成的驻波。
4. 推导靠近中的移动反射体回波频率 (f_2=f_0(c+v)/(c-v))。

## 第三轮：迁移题

1. 若行波改为沿 (-x) 方向传播，方程和波形平移分别如何改变？
2. 若驻波空间因子从 (\cos kx) 改成 (\sin kx)，哪些结论改变，哪些不变？
3. 若潜艇远离，回波频率与速度公式如何变化？
